# Ассеты и визуальный пайплайн

## Текущее состояние (прототип)
- Все персонажи, пропсы (бутылки, бочки) и окружение генерируются процедурно в рантайме.
- Спрайты персонажей и предметов создаются на Canvas 2D (512×640) в ретро-стилистике с жирным контуром и кислотными акцентами, после чего передаются как текстуры в Three.js.
- 3D-окружение двора и переулка собрано из геометрии Three.js с направленным освещением, мягкими тенями (PCFSoftShadowMap) и атмосферным туманом.
- Звуки ударов, бросков и интерфейса синтезируются локально через Web Audio API (без внешних аудиофайлов).

## Будущий пайплайн (3D и графика)
- Моделирование 3D-окружения и пропсов через Blender + MCP с экспортом в формат GLB/glTF для Three.js.
- Управление созданием объектов и манипуляция ассетами через Claude Code CLI.
- Генерация спрайтов и текстур через Antigravity-провайдер с последующей обработкой и упаковкой в атласы.
- Все внешние ассеты будут заменять процедурные текстуры модульно, без изменения логики игрового движка.
