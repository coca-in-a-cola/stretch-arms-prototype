# Длинные руки — двор да дело

Аркадная дворовая потасовка от первого лица в стиле rubber-hose мультфильмов 1930-х. Двор живой: рисованные 2D-персонажи прячутся за бочками, ящиками, забором и фургоном, высовываются, замахиваются и получают резиновой рукой. По двору гуляет пёс с нимбом — его трогать нельзя.

Стек: TypeScript + Three.js + Vite. Персонажи — 2D-спрайты на слоях глубины внутри 3D-сцены (передний план / средний / дальний), с честным перекрытием через depth buffer.

## Управление

### ПК (мышь и клавиатура)
- **Прицел:** движение мыши. Рука летит ровно в точку клика — без автонаведения и «магнитов».
- **Удар (ЛКМ или Пробел):** выброс резиновой руки (24 силы). Промах — тоже полный замах и полная цена.
- **Хватай / Бросай (ПКМ или E):** схватить бутылку или бочонок (12 сил), повторно — бросить в задиру (18 сил).
- **Пауза:** `Escape` или кнопка `Ⅱ`. При сворачивании вкладки игра встаёт на паузу сама.

### Телефон (touch)
- Касание по сцене ставит прицел в эту точку.
- Крупные кнопки (≥44px): **УДАР** и **ХВАТАЙ / БРОСАЙ**.
- Интерфейс рассчитан на 390×844 (портрет) и 844×390 (альбом).

## Как это играется
- **Честный удар:** луч из камеры через точку клика; побеждает первое, во что упёрся кулак — задира, укрытие, предмет, пёс или воздух. Попадание считается в момент прилёта кулака, поэтому задира, успевший нырнуть за укрытие, отделается «ТУК!» по бочке.
- **Задиры:** выскакивают из-за укрытия, ныряют обратно, снова выглядывают. Перед ударом краснеют, отклоняются назад и дрожат — это замах. Не успел — минус сердце.
- **Реакции:** хит-стоп ~60 мс, тряска камеры, комикс-вспышка, звёздочки у нокаутированного, крик комбо.
- **Пёс с нимбом:** гуляет и садится. Удар по нему — минус сердце и 150 очков, пёс грустит под тучкой.
- **Здоровье и силы:** 5 сердец; силы восстанавливаются 21 ед/сек.
- **Два уровня:**
  - *01 / Тихий двор* — солнечный двор, бельё на верёвке, 9 задир.
  - *02 / Шумный переулок · сумерки* — закат, неон, гирлянды, фургон и мусорные баки, 14 задир и быстрее замах. Открывается после победы во дворе.
- **Сохранение:** прогресс и рекорд — `localStorage` (`long-arms.progress.v1`), настройки — `long-arms.settings.v1`.

## Настройки
- **Звук:** синтез Web Audio (взмах, удар, нокаут, скулёж, замах), кнопка «Без звука» с сохранением.
- **Меньше движения:** уважает `prefers-reduced-motion`, есть ручной переключатель.
- **Без WebGL 2:** понятный экран-заглушка.

## Запуск

```sh
bun install
bun run dev
```

Проверка и сборка:
```sh
bun test
bun run build
PLAYWRIGHT_BROWSERS_PATH=.playwright-browsers .venv-browser/bin/python tests/browser_production.py
```

## Тесты
- `tests/game.test.ts` — правила: силы, тайминги, штрафы, сохранение, броски.
- `tests/aim.test.ts`, `tests/v2.test.ts` — свободный прицел (попадание/промах в точке удара), порядок перекрытия слоёв, отсутствие z-fighting, цикл выглядывания, прогулка пса, стоп-лист запрещённых слов в текстах игры и README.
- `tests/browser_production.py` — релизная сборка в Chromium: меню, оба уровня, момент удара, пауза, победа, поражение, портрет и альбом, ноль ошибок консоли. Скриншоты — `evidence/production/`.
