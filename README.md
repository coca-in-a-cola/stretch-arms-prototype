# Длинные руки — двор да дело

Веб-прототип аркадного тира от первого лица в ретро-стилистике rubber-hose анимации с неоновыми кислотными акцентами.
Вся графика (спрайты персонажей и 3D-окружение) и звуковые эффекты генерируются процедурно в браузере — никаких сторонних тяжёлых ассетов, внешних шрифтов или бэкенда.

## Управление

### ПК (мышь и клавиатура)
- **Прицеливание:** движение мыши по сцене.
- **Удар (ЛКМ или Пробел):** выброс резиновой руки (стоимость: 24 силы).
- **Захват / Бросок (ПКМ или E):** схватить бутылку или бочку (12 сил), повторное нажатие по задире — бросок предмета (18 сил).
- **Пауза:** клавиша `Escape` или кнопка `Ⅱ` в интерфейсе. При переключении или сворачивании вкладки игра автоматически ставится на паузу.

### Мобильные устройства (Touch)
- Касание по экрану выбирает цель.
- Крупные кнопки внизу экрана (≥44px): **УДАР** и **ХВАТАЙ / БРОСАЙ**.
- Адаптивный интерфейс под портретную и альбомную ориентацию.

## Механики и правила
- **Здоровье:** 5 сердец. Пропущенная атака задиры (розовое кольцо телеграфа) отнимает 1 сердце.
- **Пёс с нимбом:** запрещённая цель! Удар по нему отнимает 1 сердце и 150 очков.
- **Стамина:** восстанавливается со скоростью 21 ед/сек. При нуле сил атаковать нельзя.
- **Комбо:** серии удачных ударов увеличивают множитель очков.
- **Два уровня:**
  - *01 / Тихий двор:* 9 задир, комфортный обучающий темп.
  - *02 / Шумный переулок:* 14 задир, повышенный темп и сложная уличная геометрия (открывается после победы в первом дворе).
- **Перезапуск:** между попытками все 5 сердец восстанавливаются мгновенно, без мобильных таймеров ожидания.
- **Сохранение:** прогресс и рекорд сохраняются в валидируемом `localStorage` (`long-arms.progress.v1`).

## Настройки
- **Звук:** процедурный синтез на Web Audio API, кнопка `ЗВУК` (вкл/выкл с сохранением состояния).
- **Доступность:** переключатель `ДВИЖЕНИЕ` (поддержка системного `prefers-reduced-motion` и ручной оверрайд).
- **WebGL Fallback:** при отсутствии WebGL 2 на устройстве выводится понятный экран-заглушка с предложением включить ускорение.

## Запуск и разработка

```sh
bun install
bun run dev
```

Сборка для продакшена:
```sh
bun test
bun run build
```

## Тестирование
- `tests/game.test.ts` — детерминированные тесты логики (стамины, таймингов, штрафов, сохранения, бросков).
- `tests/browser_smoke.py` — проверка WebGL-рендеринга и основных механик через Playwright Chromium.
- `tests/browser_production.py` — полноценное тестирование релизной сборки (натуральное прохождение без dev-хуков, разблокировка уровней, пауза при сворачивании вкладки, мобильные вьюпорты).
